# HURR — فرع الويب (الجوال أولًا)

**الحالة:** تجهيز ملفات ومجسمات، ومعاينة قابلة للفتح من متصفح الجوال. حلقة اللعب تُبنى بعد اعتماد القصة والمراحل.

## لماذا Three.js وليس تصدير Godot للويب

| المعيار | Three.js r186 | تصدير Godot 4.7 للويب |
|---|---|---|
| حجم التحميل الأول | مكتبة ~2.3 م.ب غير مضغوطة (أقل بكثير مع gzip من GitHub Pages) + مجسمات 2.1 م.ب | محرك WebAssembly أكبر بكثير قبل أي محتوى [افتراض: لم يُقَس هنا] |
| متصفحات الجوال | WebGL2 مباشرة | يحتاج إعدادًا خاصًا للخيوط/العزل في بعض الاستضافات [افتراض يحتاج تحققًا من توثيق Godot] |
| إعادة استخدام العمل | المجسمات تُستخدم كما هي؛ العالم أُعيد كتابته بنفس الشكل والألوان | يعيد استخدام كود GDScript |
| الترخيص | MIT | MIT |

**القرار المقترح:** Three.js، لأن وقت التحميل على الجوال هو أهم معيار لألعاب الويب. البديل المرفوض حاليًا: تصدير Godot — يبقى خيارًا إن احتجنا مشاركة الكود مع نسخة Quest لاحقًا.

## ما في الفرع

- `web/index.html` — صفحة عربية RTL، شاشة تحميل بالشعار الرسمي (من مفاتيح)، خط Cairo.
- `web/src/world.js` — العالم (كثبان، الجرف المنقوش، صخور، المجثم، سماء الفجر، الشمس المائلة)، حتمي.
- `web/src/main.js` — المعاينة: نوف (مستويا تفاصيل) والصقر الحر على مجثمه، وعدّاد أداء.
- `web/src/orbit_touch.js` — لمس: إصبع للدوران، إصبعان للتقريب، لمستان للعودة.
- `web/assets/models/` — نسخ ويب من المجسمات: بلا Normals، بألوان 16-بت، **مطابقة للأصل** (فرق الموضع 0، فرق اللون ≤ 0.000008).
- `web/vendor/three/` — Three.js r186 مضمّن (MIT)، فلا اعتماد على CDN وقت التشغيل.
- `tests/web/test_web.mjs` — اختبارات Node: حتمية العالم، الميزانيات، الأحجام، الألوان، الصفحة.
- `.github/workflows/web.yml` — يختبر وينشر على GitHub Pages عند كل دفع إلى `web`.

## العوائق المعروفة

- **نوف بلا هيكل عظمي:** لا مشي ولا حركة حقيقية حتى تُبنى مجسمات بهيكل (rig) — مطلوب قبل حلقة اللعب على الجوال.
- **تفعيل GitHub Pages** يحتاج صلاحية المالك (الإعدادات ← Pages ← Source: GitHub Actions).
- لم يُختبر العرض في متصفح جوال حقيقي بعد.
